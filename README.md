# Online Retail Sales Analysis

## Overview

This project presents an end-to-end Retail Sales & Customer Analysis solution using Excel, Pandas, PostgreSQL, and Power BI. The objective is to transform raw retail transaction data into actionable business insights through data cleaning, exploratory analysis, and interactive dashboard development.

## Tools & Technologies

* Excel
* Python (Pandas)
* PostgreSQL
* Power BI
* DAX

## Project Workflow

### 1. Data Cleaning & Preprocessing

* Removed duplicate records
* Handled missing values
* Standardized data formats
* Created revenue-related fields
* Prepared the dataset for analysis

### 2. Exploratory Data Analysis (EDA)

Performed SQL-based analysis in PostgreSQL to answer key business questions:

* What are the top-selling products?
* Which customers generate the highest revenue?
* Which countries contribute the most sales?
* What are the monthly sales trends?
* Which products sell the highest quantity?

### 3. Dashboard Development

Connected PostgreSQL data to Power BI and created interactive visualizations and KPIs using DAX measures.

## Key KPIs

* Total Revenue
* Total Orders
* Unique Customers
* Total Quantity Sold
* Average Order Value
